# New Application Activation

Create an application from:

`templates/new_application/`

Do not begin by copying a previous real application.

## Required contract

Before Ball Mapper construction, record:

- application ID and purpose;
- authoritative source;
- stable ID and label;
- exact topology axes and formulas;
- scaling and metric;
- complete-case variables;
- explicit exclusions, if any;
- colour/context variables;
- historical settings as provenance only.

## P1.4-A

Reconstruct from authoritative sources and freeze an immutable input. Hash all
source and frozen artifacts.

## P1.4-B

Run the generic resolution-aware radius diagnostics using topology axes only.
Present the evidence to the user. Record a user radius only after explicit
approval.

## P1.4-C

Canonicalize by stable ID and construct/freeze the approved topology. Preserve
the topology fingerprint and object checksum.

## P1.4-D

Generate application evidence and robustness. Do not use P1.4-D colour results
to retroactively alter the radius.

## Multiple specifications

If one paper has multiple topology specifications, treat each as its own
application contract unless the relationship is explicitly defined. Separate
specifications may imply different complete-case samples.
