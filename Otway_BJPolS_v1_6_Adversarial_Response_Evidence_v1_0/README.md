# Otway BJPolS v1.6 adversarial-response evidence package v1.0

Purpose: close the empirical points raised by the fresh adversarial review of manuscript v1.5 without reopening the frozen Ball Mapper topology.

The package performs three tasks from accepted project outputs:

1. Recomputes size-aware random-label calibration for maximum local Red Wall prevalence and unique co-member mixing under the four accepted 10,000-draw benchmark contracts, for both 2021 and 2011.
2. Describes the highest-prevalence 2021 canonical Ball Mapper neighbourhoods from the frozen Corrected31D membership and scaled-coordinate files, including the highest-prevalence ball's mixed membership and graph neighbours.
3. Audits the already-accepted equal-domain block-weighting sensitivity from the targeted empirical addendum. It does not rerun that earlier sensitivity.

No radius is selected, no topology is rebuilt, and no electoral outcome enters topology construction in this package.

## Run

```bash
cd /path/to/otway-rudkin-red-wall-ball-mapper
unzip -o Otway_BJPolS_v1_6_Adversarial_Response_Evidence_v1_0.zip
cd Otway_BJPolS_v1_6_Adversarial_Response_Evidence_v1_0
chmod +x run_all.sh
./run_all.sh
```

The runner uses Python 3 standard library only. It creates a timestamped handback ZIP, SHA-256 sidecar, validation gates, CSV outputs, a manuscript-facing Markdown summary and logs.
